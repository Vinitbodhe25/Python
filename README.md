# Python Basic Program

This repository contains **20 beginner-friendly Python programs** based on Python data structures. These programs demonstrate basic operations on **Lists, Sets, Dictionaries, and Tuples**.

## 📚 Topics Covered

### 1. Lists

Programs demonstrate:

* Accessing list elements
* Finding list length
* Checking whether a list is empty
* Changing elements
* Adding elements using `append()`
* Inserting elements using `insert()`
* Removing elements using `remove()`
* Removing elements using `pop()`
* Calculating sum and average
* Finding maximum and minimum values
* Counting even and odd numbers

### 2. Sets

Programs demonstrate:

* Creating a set
* Adding elements using `add()`
* Removing elements using `remove()`
* Removing elements using `discard()`
* Clearing a set using `clear()`
* Counting set elements without using `len()`
* Checking whether a set is empty
* Combining two sets using `union()`

### 3. Dictionaries

Programs demonstrate:

* Creating dictionaries
* Adding key-value pairs
* Modifying dictionary values
* Accessing dictionary values
* Removing dictionary keys
* Getting key-value pairs using `items()`
* Checking whether a key exists
* Creating dictionaries using `zip()`
* Clearing dictionaries using `clear()`
* Combining two dictionaries using `update()`

### 4. Tuples

Programs demonstrate:

* Creating tuples
* Accessing tuple elements using indexes
* Finding tuple length
* Creating a single-item tuple
* Joining tuples using `+`
* Reversing a tuple
* Converting a tuple of characters into a string
